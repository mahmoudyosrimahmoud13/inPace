Free courses anyone can use with [inPace](../README.md).

## Use a course

1. Open a course folder below and click **Code → Download ZIP** on the main repo page (or download just that folder).
2. In inPace, go to **My courses → Add a course file** and open the zip.

## Add your course

1. Make the course in inPace (by hand or with AI), then **Share → For checkers and teachers (with answers)**.
2. Unzip it into a new folder here, named like `my-course-name`.
3. Add a row to the table above.
4. Open a pull request. A check runs automatically to make sure the course loads.

Please only share courses you wrote yourself (or made with AI), not copied from books or paid courses.
Answers are public here, so quizzes from the library are for practice. Checkers can add private questions for verified exams.
