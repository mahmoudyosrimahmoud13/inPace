# FMAA Exam Prep: Financial Management and Accounting
## inPace Course — fmaa-prc

**Version:** 1.0  
**Date:** 2026-11-16  
**Language:** English

---

## About This Course

This course prepares candidates for the **FMAA (PRC) examination** administered by Powers Resources Corporation. It covers all five exam sections across **12 modules**, progressing from core accounting principles to advanced performance analysis and professional ethics.

---

## Course Structure

| Module | Title | Sessions Covered |
|--------|-------|-----------------|
| M1 | Accounting Terminology and the Accounting Equation | Session 1 |
| M2 | Financial Statements | Session 2 |
| M3 | Corporate Governance and Internal Control | Session 3 |
| M4 | Assets | Session 4 (Part 1) |
| M5 | Liabilities and Revenue Recognition | Session 4 (Part 2) |
| M6 | Common-Size Analysis and Trend Analysis | Session 5 (Part 1) |
| M7 | Ratio Analysis | Session 5 (Part 2) |
| M8 | Budgeting | Session 6 |
| M9 | Cost Concepts and Product Costing | Sessions 7–8 |
| M10 | Overhead Costing Methods | Session 8–9 |
| M11 | Performance Analysis and Breakeven *(Capstone)* | Sessions 9–10 |
| M12 | Business Ethics and Fraud *(Capstone)* | Session 10 |

Each module includes:
- 2 lessons with clear explanations and exam tips
- A 10-question quiz (pass mark: 60% — 6 out of 10)
- Result review showing correct answers with explanations

The last two modules (M11 and M12) contain comprehensive capstone quizzes that draw on knowledge from across the course.
