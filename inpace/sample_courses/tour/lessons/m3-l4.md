# The whole book

Without a page range, the whole PDF opens. It still remembers your page.

![Small Steps](small-steps.pdf)

## Make a course from your own book

Use **Add a course → A book (PDF)**. inPace reads the book's chapters and sections, and makes each one a lesson that opens only on its own pages, like the first two lessons of this module.

In a course file, a lesson that shows part of a book looks like this:

```yaml
media: "small-steps.pdf#pages=3-4"
```
