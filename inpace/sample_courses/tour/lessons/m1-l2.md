# Code you can copy

Code in a lesson gets colours and a **Copy** button:

```python
minutes_a_day = 10
days = 30
print(f"That's {minutes_a_day * days} minutes this month!")
```

A code file can be a lesson too. Here is a small study timer:

![A study timer](study_timer.py)

Every code file in a course folder can become a lesson. A whole project folder becomes one lesson that shows all its files.
