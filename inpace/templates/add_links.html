{% trans trimmed %}How to write the list{% endtrans %}
  • {% trans trimmed %}One link per line. Each one becomes a lesson.{% endtrans %}
  • {% trans trimmed %}To name a lesson yourself, write the name, then | then the link.{% endtrans %}
  • {% trans trimmed %}A line that starts with # starts a new part of the course, for example: # Week 1{% endtrans %}
  • {% trans trimmed %}A long YouTube video: paste its link, then its chapter times under it (copy them from the video's description). Each chapter becomes its own lesson, and only that piece of the video plays.{% endtrans %}
  • {% trans trimmed %}Udemy and other websites open on their own site, because they don't allow playing inside other apps. You still tick them off in inPace.{% endtrans %}
  • {% trans trimmed %}YouTube remembers where you stopped in each lesson.{% endtrans %}
